## 🌍 Векторный Поиск (Инструкция)

### 1. Как работает поиск
Агент должен вызывать инструмент `search_tours`, который делает запрос в Supabase:
```sql
SELECT * FROM match_tours(
  embedding => 'VECTOR_FROM_USER_QUERY', 
  match_threshold => 0.6,
  match_count => 5
);
```

### 2. Пример диалога
**Пользователь:** "Хочу что-то экстремальное в горах"
**Агент (мысли):** *Ага, запрос на экстрим. Вызываю `search_tours("экстремальный отдых горы")`.*
**Агент (ответ):** "Я подобрал для вас несколько активных вариантов в горах. Обратите внимание на джип-тур и рафтинг:"
*(Показывает карусель туров)*

**Пользователь:** "А билеты до Таиланда есть?"
**Агент (ответ):** "К сожалению, я не занимаюсь авиабилетами и перелетами. Моя специализация — организация вашего отдыха и экскурсий уже на месте. Подсказать, чем заняться по прилету?"
