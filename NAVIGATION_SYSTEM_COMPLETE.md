## 🎨 Особенности

### Умный алгоритм рекомендаций

**Факторы схожести туров:**
- Категория (25%)
- Локация (20%)
- Landmarks - Jaccard similarity (20%)
- Tags - Jaccard similarity (15%)
- Themes - Jaccard similarity (10%)
- Ценовой диапазон (10%)
- Бонус за высокий рейтинг (×1.1-1.2)

**Персонализация:**
- Анализ истории бронирований пользователя
- Выявление предпочтений по категориям, локациям, landmarks
- Рекомендации на основе поведенческих паттернов

**Совместная фильтрация:**
- "Пользователи, которые заказывали этот тур, также заказывали..."
- Подсчет co-bookings между турами
- Сортировка по популярности среди похожих пользователей

### Автоматические коллекции

Создайте коллекцию с автоматическим подбором:
```json
{
  "title": "Лучшие водные экскурсии",
  "is_automatic": true,
  "auto_filters": {
    "tags": ["Водные"],
    "min_rating": 4.7,
    "max_price": 10000
  },
  "auto_limit": 12
}
```

Система автоматически подберет подходящие туры!

### Динамическая навигация

Навигация генерируется автоматически из реальных данных туров:
- Извлечение landmarks из всех туров

- Сортировка по популярности
- Фильтрация неактивных/пустых категорий
