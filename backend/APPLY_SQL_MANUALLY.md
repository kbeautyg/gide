# Ручное применение SQL для категорий

## Инструкция

1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Скопируйте весь код из файла `CREATE_CATEGORIES_TABLES.sql`
4. Вставьте в SQL Editor
5. Нажмите **Run** или **Execute**

## Что создаст этот SQL:

### Таблицы:
- ✅ `categories` - категории и рубрики
- ✅ `collections` - коллекции туров

### Категории (17 штук):
**Достопримечательности (6):**
- 🏛️ Храмы и святыни
- 🏰 Дворцы и крепости  
- 🏖️ Пляжи и острова
- ⛰️ Горы и водопады
- 🛒 Рынки и базары
- 🎨 Музеи и галереи

**Темы (6):**
- 📚 Культура и история
- 🍜 Гастрономия
- 🌿 Природа и пейзажи
- 🎿 Приключения
- 🌙 Ночная жизнь
- 🛍️ Шопинг

**Форматы (5):**
- 👤 Индивидуальные
- 👥 Групповые
- 🚶 Пешеходные
- 🚗 На транспорте
- ⛵ Водные

### Коллекции (3 штуки):
- Лучшие водные экскурсии
- Культурное наследие Азии
- Гастрономические туры

## После выполнения

SQL автоматически:
1. Создаст таблицы (если их нет)
2. Создаст индексы
3. Вставит базовые данные
4. Обновит версию миграции Alembic

Можно сразу пользоваться новой навигацией!
