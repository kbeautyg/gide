## Пошаговый запуск

### Шаг 1: Применить миграцию базы данных

#### Вариант A: Если есть виртуальное окружение
```powershell
cd backend
venv\Scripts\activate       # активация venv
alembic upgrade head
```

#### Вариант B: Если БД в Docker/Railway
```powershell
cd backend
# Убедитесь, что DATABASE_URL в .env правильный
python -c "from app.db.session import engine; print('DB connected!')"
alembic upgrade head
```

#### Вариант C: Создать БД заново
```powershell
cd backend
python reset_db.py          # Очистить и пересоздать
alembic upgrade head        # Применить все миграции
```

**Ожидаемый результат:**
```
INFO  [alembic.runtime.migration] Running upgrade 005 -> 006
✅ Миграция 006_add_tripster_content_fields применена
```

## Возможные проблемы

### "Alembic не найден"
**Решение:**
```powershell
cd backend
pip install alembic
# или
python -m pip install -r requirements.txt
```

### "Не могу применить миграцию"
**Решение 1** — откатить и применить заново:
```powershell
alembic downgrade -1
alembic upgrade head
```

**Решение 2** — пересоздать БД:
```powershell
python reset_db.py
alembic upgrade head
python seed_data.py
```

### "Frontend не запускается"
**Решение:**
```powershell
cd frontend
rm -rf node_modules package-lock.json  # на Windows: удалите вручную
npm install
npm run dev
```

### "Картинки не загружаются"
Это нормально — используются placeholder-изображения из Unsplash.
Для production замените на реальные фото.

### "Категории пустые"
Убедитесь, что:
1. Миграция применена (`alembic upgrade head`)
2. Seed-данные загружены (`python seed_data.py`)
3. Backend запущен и доступен
