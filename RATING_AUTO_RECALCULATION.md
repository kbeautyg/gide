# Автоматический пересчет рейтингов туров

## Проблема

После создания отзыва с оценкой 5.0 рейтинг тура показывал 4.9 вместо 5.0. Это происходило потому, что:

1. При создании туров через скрипты задавался статичный начальный рейтинг (например, 4.9)
2. Рейтинг не пересчитывался автоматически на основе реальных отзывов
3. Нужно было вручную запускать скрипт для синхронизации

## Решение

### 1. Создан сервис `rating_service.py`

**Файл:** `backend/app/services/rating_service.py`

Универсальная функция `recalculate_tour_rating()` которая:
- Получает все отзывы для тура
- Считает средний рейтинг
- Обновляет `rating` и `reviews_count` в таблице туров
- Если отзывов нет — ставит рейтинг 0.0

### 2. Обновлен эндпоинт создания отзывов

**Файл:** `backend/app/api/v1/endpoints/reviews.py`

При создании нового отзыва (`POST /api/v1/reviews/`):
1. Создается отзыв в БД
2. **Автоматически вызывается** `recalculate_tour_rating()`
3. Рейтинг тура обновляется на основе ВСЕХ отзывов

**Было:**
```python
# Создаем отзыв
db_review = Review(**review.dict())
db.add(db_review)
await db.commit()

# Вручную пересчитываем (старый код)
reviews = get_all_reviews()
tour.rating = calculate_average(reviews)
```

**Стало:**
```python
# Создаем отзыв
db_review = Review(**review.dict())
db.add(db_review)
await db.commit()

# Автоматически пересчитываем через сервис
await recalculate_tour_rating(db, review.tour_id)
await db.commit()
```

### 3. Обновлен скрипт `enhance_existing_tours.py`

При дозаполнении туров теперь автоматически пересчитывается рейтинг:

```python
# После обновления всех полей тура
await recalculate_tour_rating(session, tour.id)
```

### 4. Создан скрипт `fix_tour_ratings.py` (одноразовый)

**Файл:** `backend/scripts/fix_tour_ratings.py`

Скрипт для разовой синхронизации существующих туров:
- Проходит по всем турам в БД
- Пересчитывает рейтинг на основе реальных отзывов
- Обновил 413 туров из 501

Этот скрипт нужен был только один раз для исправления существующих данных.

## Как это работает теперь

### Сценарий 1: Создание нового отзыва через API

```
1. Пользователь оставляет отзыв с оценкой 5.0
   POST /api/v1/reviews/
   
2. Backend создает отзыв в БД

3. Backend автоматически вызывает recalculate_tour_rating()

4. Рейтинг пересчитывается:
   - Было: rating=4.9, reviews_count=1
   - Стало: rating=5.0, reviews_count=1
   
5. Пользователь сразу видит правильный рейтинг!
```

### Сценарий 2: Создание туров через скрипты

```
1. Скрипт создает тур с начальным rating=4.9

2. Скрипт создает отзывы для тура

3. Скрипт вызывает recalculate_tour_rating()

4. Рейтинг автоматически пересчитывается на основе отзывов

5. Тур отображается с корректным рейтингом
```

## Преимущества нового подхода

✅ **Автоматизация** - не нужно вручную запускать скрипты  
✅ **Консистентность** - рейтинг всегда соответствует отзывам  
✅ **Единое место** - вся логика в `rating_service.py`  
✅ **Легко расширять** - можно добавить weighted rating, медиану и т.д.  
✅ **Тестируемо** - сервис можно покрыть unit-тестами
