## 🚀 Быстрый старт

### 1. Применить миграцию
```bash
cd backend
alembic upgrade head
```

### 2. Заполнить данными
```bash
python seed_data.py
```

### 3. Запустить
```bash
cd ../frontend
npm run dev
```

### 4. Открыть
```
http://localhost:5173/
```

## 🎯 Основные страницы

| Страница | URL | Что нового |
|----------|-----|------------|
| Главная | `/` | Hero с SearchBar, карусели, отзывы, подписка |
| Каталог | `/tours` | Sticky поиск, категории-чипсы, FilterPanel, галереи |
| Экскурсия | `/tours/:id` | Галерея 2×2, блоки контента, отзывы, sticky sidebar |
| Город | `/destinations/:city` | Достопримечательности, гиды, SEO |
| Журнал | `/journal` | Сетка статей, фильтры по странам |
| Статья | `/journal/:slug` | Контент + связанные туры |

## 🎨 Новые компоненты

1. **TourCard** — карточка с галереей, бейджами, heart-иконкой
2. **SearchBar** — поиск в стиле Airbnb (табы + 3 поля)
3. **CategoryChips** — горизонтальный скролл категорий
4. **FilterPanel** — модальная панель фильтров
5. **Badge** — бейджи (popular, new, discount)
6. **MobileMenu** — hamburger-меню для мобильных
7. **ReviewCard** — карточка отзыва
8. **SkeletonLoader** — лоадеры при загрузке
