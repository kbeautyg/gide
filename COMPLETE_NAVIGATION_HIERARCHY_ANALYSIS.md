# 🔍 Полный анализ иерархии навигации, фильтров и рекомендаций

## 📊 Текущее состояние системы

### Структура навигации

```
Главная страница (HomePage)
├── Hero секция
├── Сезонные идеи (seasonalIdeas)
│   └── Ссылки: /tours?category={category}&location={location}
├── Динамическая навигация (DynamicNavigation)
│   └── Ссылки: /tours?themes={name} или /tours?category={name}
├── Популярные направления (destinations)
│   └── Ссылки: /tours?location={city}
└── Умные рекомендации (SmartRecommendations)

Страница туров (ToursPage)
├── CityHero (показывается при locationParam)
├── Breadcrumbs
├── LandmarksSection (показывается при locationParam && !landmarksParam)
├── Фильтры
│   ├── Страны (selectedCountries)
│   ├── Города (selectedCities)
│   ├── Категории/Темы (selectedThemes)
│   ├── Цена (selectedPriceRanges)
│   ├── Длительность (selectedDurations)
│   └── Рейтинг (selectedRatings)
├── Активные категории (отображают выбранные фильтры)
└── Список туров
```

## 🚨 Критические проблемы

### 1. Несоответствие параметров URL и состояния

**Проблема:**
- **HomePage** использует `category` в ссылках сезонных идей:
  ```typescript
  link: '/tours?category=Гастрономия&location=Бангкок'
  ```
- **ToursPage** НЕ читает параметр `category` из URL
- **ToursPage** НЕ читает параметр `themes` из URL
- **ToursPage** НЕ синхронизирует `locationParam` с `selectedCities`/`selectedCountries`
- Состояние фильтров (`selectedThemes`, `selectedCities`, etc.) полностью независимо от URL

**Последствия:**
- При переходе с главной по ссылке `/tours?category=Гастрономия&location=Бангкок`:
  - ✅ Показывается CityHero (работает)
  - ✅ Показывается LandmarksSection (работает)
  - ❌ Фильтр по категории НЕ применяется (критично!)
  - ❌ Фильтры не показывают выбранный город "Бангкок" (критично!)
  - ❌ Фильтры не показывают выбранную категорию "Гастрономия" (критично!)

### 2. Дублирование параметров `category` и `themes`

**Проблема:**
- Backend поддерживает оба параметра (`category` и `themes`)
- **DynamicNavigation** использует:
  - `themes` для type='theme'
  - `category` для type='category'
- **HomePage** использует `category` в сезонных идеях
- **ToursPage** обрабатывает только `themes` в запросе к API, но НЕ читает из URL

**Последствия:**
- Нет единообразия в использовании параметров
- Часть ссылок работает, часть нет
- Пользователь не понимает, почему некоторые фильтры не применяются

### 3. Отсутствие двусторонней синхронизации URL ↔ State

**Проблема:**
- URL → State: НЕ работает (параметры из URL не попадают в состояние фильтров)
- State → URL: НЕ работает (изменение фильтров не обновляет URL)

**Текущая реализация:**
```typescript
// ToursPage.tsx - только чтение, без синхронизации
const locationParam = searchParams.get('location')
const landmarksParam = searchParams.get('landmarks')
// Но эти значения НЕ попадают в selectedCities, selectedThemes, etc.
```

**Последствия:**
- Невозможно поделиться ссылкой с фильтрами
- Невозможно использовать кнопку "Назад" браузера
- Пользователь не видит активные фильтры в UI
- Невозможно понять, какие фильтры применены

### 4. Проблемы с иерархией навигации

**Проблема:**
- При переходе **Главная → Популярные направления → Бангкок**:
  - ✅ Показывается CityHero с изображением
  - ✅ Показывается LandmarksSection "Достопримечательности в Бангкок"
  - ✅ URL: `/tours?location=Бангкок`
  
- При переходе **Страница туров → Фильтры → Выбор города "Бангкок"**:
  - ❌ CityHero НЕ показывается (locationParam не обновляется)
  - ❌ LandmarksSection НЕ показывается
  - ❌ URL НЕ обновляется
  - ❌ Состояние фильтров обновляется, но не синхронизируется с URL

**Последствия:**
- Разные пути ведут к разному отображению
- Нет единообразия в навигации
- Пользователь не понимает, почему интерфейс работает по-разному

### 5. Проблемы с отображением активных фильтров

**Проблема:**
- Блок "Активные категории" показывает только фильтры из состояния (`selectedThemes`, `selectedCities`, etc.)
- НЕ показывает фильтры из URL (`locationParam`, `landmarksParam`)
- При загрузке страницы с параметрами фильтры не синхронизируются

**Текущая реализация:**
```typescript
const activeFiltersCount = 
  selectedCountries.length + 
  selectedCities.length + 
  selectedThemes.length + 
  (landmarksParam ? 1 : 0)  // Только landmarks из URL!
```

**Последствия:**
- Пользователь не видит все активные фильтры
- Невозможно удалить фильтры из URL через UI
- Нет полной картины примененных фильтров

### 6. Проблемы с DynamicNavigation

**Проблема:**
- Использует разные параметры для разных типов:
  - `landmark` → `landmarks`
  - `tag` → `tags`
  - `theme` → `themes`
  - `category` → `category`
  - `location` → `location`
- Но ToursPage не обрабатывает все эти параметры корректно

**Последствия:**
- Ссылки из DynamicNavigation могут не работать корректно
- Нет единообразия в навигации

## 🎯 Требования к исправлению

### Обязательные требования:

1. **Единая система параметров URL:**
   - Определить четкую иерархию: `category` или `themes`?
   - Унифицировать использование параметров во всех компонентах
   - Обеспечить обратную совместимость

2. **Двусторонняя синхронизация URL ↔ State:**
   - URL → State: При загрузке страницы читать все параметры из URL и применять к фильтрам
   - State → URL: При изменении фильтров обновлять URL
   - Использовать `useNavigate` или `window.history.pushState`
   - Сохранять все параметры в URL

3. **Единообразное отображение:**
   - CityHero показывается всегда при наличии `location` в URL или состоянии
   - LandmarksSection показывается всегда при наличии `location` и отсутствии `landmarks`
   - Не зависит от пути навигации

4. **Видимость активных фильтров:**
   - Показывать все активные фильтры из URL и состояния
   - Позволить удалять фильтры через UI
   - Добавить кнопку "Сбросить все" которая очищает URL

5. **Поддержка всех параметров:**
   - `location` (город или страна)
   - `themes` или `category` (категории/темы)
   - `landmarks` (достопримечательности)
   - `tags` (теги)
   - `price` (цена: min_price, max_price)
   - `duration` (длительность: duration_min, duration_max)
   - `rating` (рейтинг: min_rating)
   - `guests` (количество гостей)
