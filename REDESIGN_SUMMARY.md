## 🎭 Анимации и интерактивность

### Framer Motion эффекты
- **Fade-in при скролле**: блоки плавно появляются снизу
- **Stagger**: карточки появляются по очереди с задержкой
- **Hover**: карточки приподнимаются, тени усиливаются
- **Modal animations**: плавное появление/исчезновение панелей
- **Skeleton loaders**: shimmer-эффект при загрузке

### Созданные утилиты
`frontend/src/lib/animations.ts`:
- `fadeInUp`, `fadeInLeft`, `fadeInRight`
- `staggerContainer`, `staggerItem`
- `cardHover`, `modalVariants`, `slideInRight`

## 🛠 Следующие шаги

### Для запуска
1. Применить миграцию:
   ```bash
   cd backend
   # Если есть venv, активируйте
   alembic upgrade head
   ```

2. Заполнить данными:
   ```bash
   python seed_data.py
   ```

3. Запустить frontend:
   ```bash
   cd frontend
   npm install  # если нужно
   npm run dev
   ```
