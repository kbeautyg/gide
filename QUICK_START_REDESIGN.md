## Новые возможности

### Для пользователей
1. **Поиск**: табы "Экскурсии/Впечатления" + 3 поля (Куда/Даты/Гости)
2. **Фильтры**: модальная панель с категориями, ценой, длительностью, рейтингом
3. **Категории**: 12+ тем (Винные, Казбеги, Гастрономические...)
4. **Галереи**: листать фото стрелками или точками
5. **Избранное**: heart-иконка на каждой карточке
6. **Отзывы**: с фото, рейтингами, кнопкой "ещё"
7. **Мобильное меню**: hamburger слева

### Анимации
- Карточки появляются по очереди (stagger)
- Hover: карточки приподнимаются
- Skeleton loaders при загрузке
- Модальные окна slide-in
- Плавные переходы везде

## Если что-то не работает

### Ошибка миграции
```powershell
cd backend
python -m alembic downgrade -1
python -m alembic upgrade head
```

### Ошибки в консоли браузера
- Проверьте, что backend запущен
- Проверьте API endpoints в DevTools → Network

### Не видно изменений
- Очистите кэш браузера (Ctrl+F5)
- Перезапустите `npm run dev`
