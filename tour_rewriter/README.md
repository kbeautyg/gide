# Tour Rewriter GUI

Программа для рерайта туров через ChatGPT с удобным визуальным интерфейсом.

## Установка

```bash
cd tour_rewriter
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откройте в браузере: http://localhost:5000

## Возможности

- 📋 **Просмотр всех туров** — список из JSON файлов Tripster
- 📤 **Предпросмотр запроса** — видно что отправляется в ChatGPT
- 📥 **Просмотр ответа** — результат и raw ответ от API
- 🚀 **Обработка одного тура** — тестирование на отдельных турах
- ▶️ **Пакетная обработка** — автоматическая обработка всех туров
- ⏹️ **Остановка и продолжение** — можно остановить и продолжить с места остановки
- 💾 **Экспорт результатов** — сохранение в JSON файл
- 📜 **История обработки** — все результаты в одном месте

## Горячие клавиши

- `↑` / `←` — предыдущий тур
- `↓` / `→` — следующий тур
- `Ctrl + Enter` — обработать текущий тур

## API ключ

Нужен OpenAI API ключ (начинается с `sk-...`).
Получить можно на: https://platform.openai.com/api-keys
