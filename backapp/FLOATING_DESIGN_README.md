# 🎨 Floating/Overlay Design - Главный экран

## Что было изменено

Главный экран был полностью переделан в стиле **"Floating/Overlay Design"** (плавающий дизайн без блоков и рамок), вдохновленный современными стриминговыми сервисами типа Kinopoisk, Netflix, YouTube.

## 🎯 Ключевые особенности нового дизайна

### 1. **Hero Section на весь экран**
- Полноэкранная hero-секция (`h-screen`)
- Фоновое изображение с параллакс эффектом
- Плавная анимация появления (scale от 1.1 до 1)

### 2. **Градиентные оверлеи для читаемости**
```css
- Вертикальный градиент: from-black/70 via-black/40 to-black/80
- Горизонтальный градиент: from-black/50 via-transparent to-black/50
```
Эти оверлеи обеспечивают читаемость текста на любом фоне.

### 3. **Плавающий текст БЕЗ блоков**
- Огромный заголовок (до 9xl на больших экранах)
- Текст с тенями для объема: `textShadow: '0 4px 30px rgba(0,0,0,0.8)'`
- Никаких карточек, рамок или блоков
- Текст выровнен по левому краю для драматичности

### 4. **Минималистичные кнопки**
- Белая основная кнопка с тенью
- Прозрачная кнопка с обводкой и backdrop-blur
- Круглые кнопки (rounded-full)
- Hover эффекты с масштабированием

### 5. **Живая статистика прямо на фоне**
- Статистика размещена внизу hero-секции
- Без карточек, просто цифры с тенями
- Плавающий стиль

### 6. **Scroll Indicator**
- Анимированный индикатор прокрутки
- Плавная анимация вверх-вниз
- Минималистичный дизайн

## 🎨 Стилистические решения

### Цветовая палитра
- Черный фон для hero (`bg-black`)
- Белый текст с тенями
- Акцентный цвет: `text-airbnb-rausch` (красный)
- Градиенты для глубины

### Типографика
- Огромные заголовки: `text-5xl md:text-7xl lg:text-8xl xl:text-9xl`
- Тонкие шрифты для описаний: `font-light`
- Жирные заголовки: `font-bold`
- Межстрочный интервал: `leading-[0.9]` для компактности

### Анимации
- Framer Motion для плавных переходов
- Параллакс эффект на фоне
- Последовательное появление элементов с задержками
- Hover эффекты с масштабированием

## 🔧 Технические детали

### Использованные технологии
- React + TypeScript
- Framer Motion (анимации)
- Tailwind CSS (стили)
- Lucide React (иконки)

### Адаптивность
- Мобильные: `text-5xl`, `px-8`
- Планшеты: `md:text-7xl`, `md:px-16`
- Десктоп: `lg:text-8xl`
- Большие экраны: `xl:text-9xl`

## 🎬 Вдохновение

Дизайн вдохновлен:
- **Kinopoisk** - плавающий текст на фоне фильмов
- **Netflix** - hero-секции с оверлеями
- **YouTube** - минималистичный подход


## 📝 Примечания

- Фоновое изображение можно заменить на видео для еще большего эффекта
- Можно добавить автоматическую смену фоновых изображений
- Scroll indicator можно скрыть на мобильных устройствах
- Градиенты можно настроить под конкретные изображения

## ✨ Результат

Получился современный, минималистичный дизайн в стиле "Content-First", где контент (изображение и текст) находятся на первом плане, а интерфейс максимально незаметен.
