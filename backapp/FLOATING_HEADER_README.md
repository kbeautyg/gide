# 🎨 Floating Glassmorphism Header - Плавающий хедер

## Что было изменено

Хедер был полностью переделан в стиле **"Floating Glassmorphism"** (плавающие элементы с эффектом жидкого стекла).

## 🎯 Ключевые особенности нового дизайна

### 1. **Floating Header (Плавающий хедер)**
- `fixed top-4 left-4 right-4` - хедер плавает над контентом с отступами
- Не прилипает к краям экрана
- Создает ощущение легкости и воздушности

### 2. **Лого в белой капсуле (слева)**
```css
bg-white rounded-full px-6 py-3 shadow-lg border border-gray-200/50
```
- Белый фон с тенью
- Круглая капсула (rounded-full)
- Тонкая обводка для четкости
- Отдельный элемент слева

### 3. **Glassmorphism эффект (жидкое стекло)**
```css
bg-white/80 backdrop-blur-xl rounded-full shadow-lg border border-white/50
```

**Что создает эффект жидкого стекла:**
- `bg-white/80` - полупрозрачный белый фон (80% прозрачности)
- `backdrop-blur-xl` - размытие фона за элементом
- `border border-white/50` - полупрозрачная обводка
- `shadow-lg` - мягкая тень для глубины

### 4. **Три отдельных блока**
1. **Лого** - белая капсула слева
2. **Навигация** - glassmorphism капсула по центру
3. **Кнопки** - glassmorphism капсула справа

### 5. **Активные ссылки**
- Активная страница: `bg-airbnb-rausch text-white` (красная капсула)
- Неактивные: прозрачные с hover эффектом
- Все ссылки в капсулах (rounded-full)

### 6. **Градиентные кнопки**
```css
bg-gradient-to-r from-airbnb-rausch to-pink-600
```
- Красивый градиент от красного к розовому
- Hover эффект с масштабированием (`hover:scale-105`)
- Увеличение тени при наведении

## 🎨 Стилистические решения

### Эффект жидкого стекла (Glassmorphism)
- **Прозрачность:** `bg-white/80` (80% непрозрачности)
- **Размытие:** `backdrop-blur-xl` (очень сильное размытие)
- **Обводка:** `border border-white/50` (50% прозрачности)
- **Тени:** `shadow-lg` для глубины

### Капсулы (Pills)
- Все элементы: `rounded-full`
- Padding: `px-6 py-3` для комфорта
- Hover: `hover:bg-gray-100/80` (полупрозрачный серый)

### Активные состояния
- Красная капсула для активной страницы
- Градиентная кнопка для главных действий
- Масштабирование при hover

## 🔧 Технические детали

### Fixed позиционирование
```css
fixed top-4 left-4 right-4
```
- Хедер всегда видим
- Отступы со всех сторон (16px)
- Плавает над контентом

### Компенсация высоты
```html
<div className="h-24" />
```
Добавлен отступ после хедера, чтобы контент не прятался под ним.

### Адаптивность
- **Мобильные:** Hamburger в отдельной капсуле
- **Десктоп:** Полная навигация
- **Планшеты:** Адаптивные отступы
