# 🖼️ Railway Root Directory - Визуальная инструкция

## 🎯 Где найти Root Directory в Railway

### Шаг 1: Откройте проект
1. Зайдите на https://railway.app
2. Найдите ваш проект в списке
3. Кликните на него

### Шаг 2: Выберите сервис
Вы увидите один или несколько сервисов (прямоугольников).
Кликните на тот, который деплоится (обычно это единственный).

### Шаг 3: Откройте Settings
В верхнем меню вы увидите вкладки:
```
Deployments  Metrics  Settings  Variables  ...
                           ↑
                    КЛИКНИТЕ СЮДА
```

### Шаг 4: Найдите Root Directory

Прокрутите страницу вниз. Вы увидите секции:
- **General**
- **Environment** 
- **Networking**
- **Service Settings** ← ВОТ ЭТА СЕКЦИЯ!

В секции **Service Settings** будет:
```
┌─────────────────────────────────────┐
│ Service Name                        │
│ [thaiguide-backend-production]      │
├─────────────────────────────────────┤
│ Root Directory (optional)           │ ← ВОТ ЭТО ПОЛЕ!
│ [                          ]        │
└─────────────────────────────────────┘
```

### Шаг 5: Введите значение

Кликните в поле **Root Directory** и введите:
```
backend
```

**ВАЖНО:**
- ✅ Правильно: `backend`
- ❌ Неправильно: `/backend`
- ❌ Неправильно: `backend/`
- ❌ Неправильно: `./backend`

### Шаг 6: Сохраните

Просто кликните где-то вне поля. Railway автоматически сохранит изменение.

Вы должны увидеть небольшое уведомление "Settings updated" или что-то подобное.

### Шаг 7: Redeploy

1. Вернитесь на вкладку **Deployments** (вверху)
2. Вы увидите список деплоев
3. Найдите самый последний (сверху)
4. Справа от него есть три точки `⋮` или `...`
5. Кликните на них
6. В меню выберите **"Redeploy"**

Railway начнет новый деплой с правильными настройками!

## ✅ Как понять что всё работает?

### В логах сборки вы увидите:

**ДО (неправильно):**
```
install │ python3.11 -m pip install -r backend/requirements.txt
```

**ПОСЛЕ (правильно):**
```
install │ python3.11 -m pip install -r requirements.txt
```

Обратите внимание: **нет** слова `backend/` перед `requirements.txt`!

## 🔍 Не можете найти Root Directory?

### Вариант А: Используйте поиск
1. Откройте Settings
2. Нажмите `Ctrl+F` (Windows) или `Cmd+F` (Mac)
3. Введите: `root directory`
4. Браузер подсветит поле

### Вариант Б: Проверьте версию Railway
Если вы используете старую версию интерфейса Railway:
1. Зайдите в настройки проекта (не сервиса!)
2. Там может быть опция "Build Settings"
3. Ищите "Source Directory" или "Root Path"

### Вариант В: Используйте Railway CLI
```bash
# Установите CLI
npm install -g @railway/cli

# Логин
railway login

# Подключитесь к проекту
railway link

# Установите Root Directory
railway variables set ROOT_DIRECTORY=backend
```

## 🆘 Если всё равно не работает

### Создайте новый сервис с правильными настройками:

1. В Railway создайте **новый сервис**
2. Выберите "Deploy from GitHub repo"
3. Выберите ваш репозиторий
4. **СРАЗУ** в мастере настройки найдите Root Directory
5. Установите `backend`
6. Завершите создание

Это иногда проще чем искать настройку в уже созданном сервисе.
