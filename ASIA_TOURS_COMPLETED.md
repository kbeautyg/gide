## 🚀 Как добавить новые экскурсии

### Вариант 1: Добавить страну
1. Создать файл `scripts/create_<country>_tours.py`
2. Определить массив туров (компактный формат)
3. Использовать `tour_generator` для автозаполнения
4. Запустить скрипт

### Вариант 2: Добавить город в существующую страну
1. Открыть соответствующий скрипт (например `create_thailand_tours.py`)
2. Добавить новый массив `new_city_tours = [...]`
3. Применить генератор и добавить в общий список
4. Запустить скрипт

### Вариант 3: Массовое добавление
Использовать `expand_tours_to_500.py` для автоматического создания вариаций
