## Проверка совпадения чисел

Теперь ВСЕ числа совпадают, потому что берутся из реальной базы данных:

| Место | Источник данных | Пример |
|-------|----------------|--------|
| Главная → "Бангкок" | `COUNT(*) FROM tours WHERE location LIKE '%Бангкок%'` | 85 экскурсий |
| ToursPage → Hero | `LENGTH(filteredTours)` после фильтрации | 85 экскурсий |
| Достопримечательность | `COUNT(*) FROM tours WHERE location LIKE '%Бангкок%' AND landmarks @> '["Храм Ват Арун"]'` | 12 экскурсий |
| Сумма достопримечательностей | Может быть > общего числа | ⚠️ НОРМАЛЬНО! Один тур может иметь несколько landmarks |
