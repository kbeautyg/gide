Документация по развертыванию проекта Gide

Общие сведения
Проект представляет собой веб-приложение, состоящее из:
1.  Frontend: React (SPA), раздается через Nginx.
2.  Backend: Python FastAPI.
3.  Автоматизация: Сервис вебхуков для автодеплоя.

Все компоненты упакованы в Docker-контейнеры. Для запуска используется docker-compose.

*   Свободные порты: 8080 (для приложения) и 9000 (для вебхука) на локальном интерфейсе.
*   Настроенный Nginx на хосте (для проксирования домена).

3. Настройка Nginx (на хосте)

Чтобы сайт открывался по домену и работал автодеплой, настройте проксирование в системном Nginx.

Конфиг /etc/nginx/sites-available/gide.conf:


server {
    listen 80;
    server_name gide.ваш-домен.ru; # УКАЖИТЕ РЕАЛЬНЫЙ ДОМЕН

    # Основное приложение (Frontend + API)
    # Проксируем на внутренний Nginx в Docker (порт 8080)
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # Автодеплой (Webhooks)
    # Проксируем на сервис вебхуков (порт 9000)
    location /webhook {
        proxy_pass http://127.0.0.1:9000/webhook;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}


После создания конфига выполните:

ln -s /etc/nginx/sites-available/gide.conf /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
certbot --nginx -d gide.ваш-домен.ru


---

Как работает Автодеплой (Информация для разработчика)

В сборку включен контейнер gide_webhook, который слушает порт 9000.
При получении POST-запроса на /webhook он запускает скрипт deploy.sh внутри сервера.

Скрипт deploy.sh:
1.  Делает git pull.
2.  Пересобирает контейнеры: docker-compose -f docker-compose.prod.yml up --build -d.

Вам (Администратору) настраивать Git-хуки НЕ НУЖНО.
Вам нужно только обеспечить, чтобы запрос на https://gide.ваш-домен.ru/webhook доходил до порта 9000 (это делает конфиг Nginx выше).
