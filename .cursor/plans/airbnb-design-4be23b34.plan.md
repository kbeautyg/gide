# Редизайн в стиле Airbnb + контент Tripster

## 1. Дизайн-система и UI-kit (Airbnb-стиль)

### Цветовая палитра

- **Основа**: чистый белый фон `#FFFFFF`, светло-серый `#F7F7F7` для секций
- **Акценты**: заменить тропические цвета на нейтральные Airbnb-тона
  - Основной розовый `#FF385C` (брендовый цвет Airbnb)
  - Тёмно-серый для текста `#222222`
  - Средний серый `#717171` для вторичного текста
  - Подсветка поиска/CTA `#00A699` (бирюзовый, как у Airbnb)
- **Тени**: мягкие многослойные `box-shadow: 0 2px 16px rgba(0,0,0,0.12)`
- **Скругления**: увеличить до `12px` для карточек, `8px` для кнопок

### Типографика

- **Заголовки**: Circular (Airbnb-шрифт) или замена на Inter/Manrope
  - H1: 48px, weight 700, letter-spacing -0.02em
  - H2: 32px, weight 600
  - H3: 24px, weight 600
- **Текст**: 16px основной, 14px вспомогательный, line-height 1.6
- **Воздух**: увеличить padding/margin между блоками (минимум 80px между секциями)

### Компоненты (обновить `frontend/src/components/ui/`)

**SearchBar** (новый компонент)

- Поисковый блок с табами "Экскурсии / Туры / Впечатления"
- Поля: `Куда` (autocomplete), `Даты` (range picker), `Гости` (stepper)
- Анимация раскрытия полей, sticky-режим при скролле
- Использовать Framer Motion для плавных появлений

**Card**

- Переработать: галерея изображений с точками навигации внизу
- Hover-эффект: лёгкий подъём `translateY(-4px)` + усиление тени
- Бейджи "Популярно", "Новое", "Скидка X%" (абсолютное позиционирование)
- Heart-иконка "Избранное" (правый верхний угол)

**FilterPanel** (новый компонент)

- Модальное окно в стиле Airbnb с секциями:
  - Диапазон цен (слайдер с двумя ручками)
  - Категории (чипсы с иконками, мультиселект)
  - Длительность (радиокнопки: до 3ч, 3-6ч, 6+ часов)
  - Рейтинг (чекбоксы 4.5+, 4.0+)
  - Включено в цену (чекбоксы: трансфер, обед, билеты)
- Футер с "Сбросить" и "Применить (X)"

**Calendar** (новый компонент)

- Два месяца side-by-side на десктопе
- Табы: "Даты" / "Месяцы" / "Гибко"
- Подсветка диапазона, disabled прошлые даты
- Гибкие даты: радио-группа "±1/2/3/7 дней"

**GuestStepper** (новый компонент)

- Секции: Взрослые (13+), Дети (2-12), Младенцы (<2)
- Кнопки +/– с плавной анимацией счётчика

**Badge** (новый компонент)

## 6. Компоненты анимаций (Framer Motion)

### Установка зависимостей

Framer Motion уже установлен (`package.json`), добавить:

```bash
npm install react-intersection-observer
```

### Паттерны анимаций

**Fade-in при появлении**:

```tsx
<motion.div
  initial={{ opacity: 0, y: 20 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true }}
  transition={{ duration: 0.6 }}
>
```

**Stagger для сетки карточек**:

```tsx
<motion.div variants={containerVariants} initial="hidden" animate="visible">
  {items.map((item, i) => (
    <motion.div key={i} variants={itemVariants}>
      <Card />
    </motion.div>
  ))}
</motion.div>
```

**Hover-эффекты**:

```tsx
<motion.div
  whileHover={{ scale: 1.02, boxShadow: "0 8px 24px rgba(0,0,0,0.15)" }}
  transition={{ duration: 0.2 }}
>
```

**SearchBar expand**:

- При клике на поле `Где` — расширение блока с анимацией высоты
- Подсказки появляются с `fadeIn` + `slideDown`

**Skeleton Loader**:

```tsx
<motion.div
  animate={{ opacity: [0.5, 1, 0.5] }}
  transition={{ duration: 1.5, repeat: Infinity }}
  className="bg-gray-200 rounded-lg"
/>
```
