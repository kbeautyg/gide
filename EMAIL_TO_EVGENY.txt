Это Денис Кузиков по вопросу развертывания проекта Gide (Inturex).

Ранее мы обсуждали возможность размещения проекта на сервере, где уже есть другие сайты. Чтобы сделать это максимально безопасно и не "сломать" текущее окружение (версии PHP, системные библиотеки), мы подготовили решение на базе Docker.

Почему Docker?
1. Изоляция: Проект (Backend на Python + Frontend на React + зависимости) будет работать внутри контейнеров и не затронет настройки вашего сервера.
2. Безопасность: Мы не будем ставить Python/Node.js глобально в систему.
3. Простота обновлений: Мы настроили скрипт, который сам будет обновлять контейнеры при пуше в Git.

Что нужно сделать:
Я подготовил для вас пошаговую инструкцию (см. ниже или во вложении). Она содержит готовые команды, которые нужно выполнить на сервере:
1. Клонировать репозиторий.
2. Создать файл .env с настройками (ключи я предоставил).
3. Запустить одну команду docker-compose для старта.
4. Добавить небольшой конфиг в ваш Nginx, чтобы направить поддомен на порт контейнера.

Все файлы конфигурации (docker-compose, nginx.conf, скрипты деплоя) уже лежат в репозитории, ничего писать с нуля не нужно.

Буду благодарен, если сможете выполнить эти шаги. Если возникнут вопросы по Docker-части — я на связи.
