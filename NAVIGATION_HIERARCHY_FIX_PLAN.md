# План исправления иерархии навигации, фильтров и рекомендаций

## 🔍 Выявленные проблемы

### 1. Несоответствие параметров URL
**Проблема:**
- На главной странице используются ссылки с параметром `category`: `/tours?category=Гастрономия&location=Бангкок`
- В ToursPage обрабатывается только параметр `themes`, но не `category`
- DynamicNavigation использует `themes` для type='theme', но `category` для type='category'
- Backend API поддерживает оба параметра (`category` и `themes`)

**Последствия:**
- При переходе с главной по ссылке `/tours?category=Гастрономия&location=Бангкок` фильтр по категории не применяется
- Пользователь видит туры по Бангкоку, но без фильтрации по категории "Гастрономия"

### 2. Отсутствие синхронизации URL параметров с состоянием фильтров
**Проблема:**
- ToursPage читает параметры из URL (`locationParam`, `landmarksParam`), но не синхронизирует их с состоянием фильтров (`selectedCities`, `selectedThemes`)
- При переходе по ссылке `/tours?location=Бангкок`:
  - ✅ Показывается CityHero (правильно)
  - ✅ Показывается LandmarksSection (правильно)
  - ❌ Фильтры не показывают выбранный город "Бангкок"
  - ❌ Фильтры не показывают выбранную категорию

**Последствия:**
- Пользователь не видит активные фильтры в интерфейсе
- Невозможно понять, какие фильтры применены
- Невозможно легко сбросить фильтры через UI

### 3. Проблемы с иерархией навигации
**Проблема:**
- При переходе с главной страницы → Популярные направления → Бангкок:
  - Показывается CityHero с изображением
  - Показывается LandmarksSection "Достопримечательности в Бангкок"
  - Но эту же страницу нельзя получить через обычные фильтры на странице туров
  - Фильтры не синхронизируются с URL

**Последствия:**
- Разные пути ведут к одному состоянию, но UI отображается по-разному
- Нет единообразия в навигации
- Пользователь не понимает, как вернуться к фильтрам

### 4. Отсутствие единой системы управления URL параметрами
**Проблема:**
- Каждый компонент сам формирует URL параметры
- Нет централизованной логики синхронизации URL ↔ State
- При изменении фильтров URL не обновляется автоматически

**Последствия:**
- Невозможно поделиться ссылкой с текущими фильтрами
- Невозможно использовать кнопку "Назад" браузера для отмены фильтров
- Сложно отслеживать состояние фильтров

## 📋 План исправления

### Этап 1: Унификация параметров URL (Приоритет: ВЫСОКИЙ)

#### 1.1 Создать единую систему маппинга параметров
- Создать утилиту `urlParams.ts` для работы с URL параметрами
- Маппинг: `category` → `themes` (если category это тема)
- Обработка обоих параметров в ToursPage

#### 1.2 Исправить ссылки на главной странице
- Заменить `category` на `themes` в HomePage.tsx (строки 40, 45, 50)
- Или добавить обработку обоих параметров

#### 1.3 Обновить DynamicNavigation
- Убедиться, что все ссылки используют правильные параметры
- Проверить маппинг типов: `theme` → `themes`, `category` → `themes` или `category`

### Этап 2: Синхронизация URL ↔ State (Приоритет: ВЫСОКИЙ)

#### 2.1 Создать хук `useUrlFilters`
- Синхронизация URL параметров с состоянием фильтров
- Автоматическое чтение параметров при загрузке
- Автоматическое обновление URL при изменении фильтров

#### 2.2 Обновить ToursPage
- Использовать `useUrlFilters` вместо локального состояния
- При загрузке читать все параметры из URL:
  - `location` → `selectedCities` или `selectedCountries`
  - `themes` или `category` → `selectedThemes`
  - `landmarks` → показать в активных фильтрах
  - `price` → `selectedPriceRanges`
  - `duration` → `selectedDurations`
  - `rating` → `selectedRatings`

#### 2.3 Обновить обработчики фильтров
- При изменении фильтров обновлять URL
- Использовать `useNavigate` или `window.history.pushState`
- Сохранять все параметры в URL

### Этап 3: Улучшение иерархии навигации (Приоритет: СРЕДНИЙ)

#### 3.1 Унифицировать отображение CityHero
- Показывать CityHero всегда, когда есть `location` параметр
- Независимо от того, как пользователь попал на страницу

#### 3.2 Унифицировать отображение LandmarksSection
- Показывать LandmarksSection всегда, когда есть `location` и нет `landmarks`
- Обновлять заголовок: "Достопримечательности в {location}"

#### 3.3 Улучшить breadcrumbs
- Показывать полную цепочку: Главная > Страна > Город > Категория
- Делать breadcrumbs кликабельными для быстрой навигации

### Этап 4: Улучшение UX фильтров (Приоритет: СРЕДНИЙ)

#### 4.1 Показывать активные фильтры из URL
- При загрузке страницы с параметрами показывать их в блоке "Активные категории"
- Позволить удалять фильтры через UI

#### 4.2 Улучшить блок "Активные категории"
- Показывать все активные фильтры из URL
- Добавить кнопку "Сбросить все" которая очищает URL параметры

#### 4.3 Синхронизировать фильтры городов/стран
- Если в URL есть `location=Бангкок`, автоматически выбрать город в фильтрах
- Если в URL есть `location=Таиланд`, автоматически выбрать страну

### Этап 5: Тестирование и проверка (Приоритет: ВЫСОКИЙ)

#### 5.1 Тестовые сценарии
1. Главная → Популярные направления → Бангкок
   - ✅ Должен показываться CityHero
   - ✅ Должен показываться LandmarksSection
   - ✅ Фильтры должны показывать выбранный город "Бангкок"
   - ✅ URL должен быть `/tours?location=Бангкок`

2. Главная → Сезонные идеи → Категория + Город
   - ✅ Должны применяться оба фильтра
   - ✅ Фильтры должны отображаться в UI

3. Страница туров → Выбор фильтров → Применение
   - ✅ URL должен обновляться
   - ✅ Фильтры должны применяться
   - ✅ Можно поделиться ссылкой

4. Прямой переход по ссылке с параметрами
   - ✅ Все параметры должны применяться
   - ✅ Фильтры должны синхронизироваться
